NOT RIGHT
Version 1.0.0

Hides every guild chat message containing "yeah right" (or "yeahright"),
from anyone, including you. Matching is case-insensitive and ignores
punctuation, the same as the YeahRight addon.

Only your own chat window is affected. Other players still see the messages.

INSTALLATION
Download the latest zip from:
https://github.com/Topherr/NotRight/releases/latest

Copy the NotRight folder into Interface\AddOns\, enable "Not Right" at
character select, then log in or /reload.

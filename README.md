A World of Warcraft addon that quietly hides every **"yeah right"** from guild chat.

## What it does

- Hides any guild message containing `yeah right` or `yeahright`, from anyone, including you.
- Matching ignores case, punctuation, and extra spacing: `Yeah Right!`, `yeah... right`, and `YeAhRiGhT` are all hidden.
- Longer words such as `yeahrightly` are left alone.
- Only your own chat window is affected. Everyone else still sees the messages.

## Installation

1. Download the latest zip from **[Releases](https://github.com/Topherr/NotRight/releases/latest)**.
2. Extract the `NotRight` folder into `World of Warcraft/<client>/Interface/AddOns/`.
3. At character select, open **AddOns** and enable **Not Right**.
4. Log in, or type `/reload` if you're already in game.

Pairs well (or badly) with [YeahRight](https://github.com/Topherr/YeahRight).
